## 4. TROUBLESHOOTING & RECOVERY RUNBOOK (Fix Instructions)

### Issue A: "WhatsApp QR code is not loading or says disconnected"
1. **Diagnosis**: Check if the Docker container is running:
   ```powershell
   docker ps
   ```
   You should see `evolution-api`, `evolution-postgres`, and `evolution-redis`.
2. **Fix**: If stopped, restart the Evolution API stack:
   ```powershell
   cd C:\Users\Dhrubo\.gemini\antigravity\scratch\ai-sdr
   docker compose up -d
   ```
3. **Verify**: Open `http://localhost:8080` in your browser. It should return Evolution API status. Refresh `http://localhost:3000/whatsapp`.

---

### Issue B: "Voice Call WebRTC mic error: Permission Denied"
1. **Diagnosis**: The browser blocked microphone access on the `/talk/[token]` page.
2. **Fix**:
   - In Chrome/Edge: Click the lock icon in the URL bar (left of `localhost:3000`).
   - Change **Microphone** from "Block" to "Allow".
   - Refresh the page and click "Start Voice Call".

---

### Issue C: "Outbound Voice Call blocked by Compliance Gate"
1. **Diagnosis**: Error indicates: `Outbound calling restricted outside 09:00–21:00 IST` or `Missing DLT Entity ID`.
2. **Fix**:
   - Verify the current time in India (IST). Commercial calls cannot run at midnight.
   - Go to `http://localhost:3000/settings` and verify `DLT Principal Entity ID` is filled with a valid registration number (e.g. `110155223344`).
   - Ensure caller ID starts with `140` or `1600`.

---

### Issue D: "Port 3000 is busy / Address already in use"
1. **Diagnosis**: A background Next.js process is already occupying port 3000.
2. **Fix**:
   ```powershell
   Stop-Process -Id (Get-NetTCPConnection -LocalPort 3000).OwningProcess -Force
   npm start
   ```
